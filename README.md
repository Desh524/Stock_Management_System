# 🗃️ Stock Management System

A desktop-based stock management system developed using C# to streamline inventory tracking and product management for small to medium-sized businesses.

---

## 🚀 Features

- ✅ Add, update, and delete product information  
- 📦 Monitor real-time stock levels   
- 🔍 Search functionality for quick product lookup  
- 🗂 Category-based product grouping  
- 🖥️ User-friendly Windows Forms interface

---

## 🛠 Tech Stack

- **Language:** C#   
- **Database:** SSMS Server  
- **UI:** Windows Forms
